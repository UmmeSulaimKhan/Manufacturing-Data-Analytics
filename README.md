# Manufacturing Data Analytics Project

## 📌 Project Overview

This project focuses on analyzing manufacturing data to evaluate production performance, quality, rejection rates, wastage, and operational efficiency.

The project demonstrates an end-to-end data analytics workflow using **Excel, SQL, Power BI, and Tableau**, from data preparation and analysis to interactive dashboard development.

## 🛠️ Tools & Technologies

* **Excel** – Data preparation, cleaning, and initial analysis
* **SQL / MySQL** – Data querying and analysis
* **Power BI** – Data modeling, DAX calculations, and interactive dashboard
* **Tableau** – Data visualization and interactive dashboard development

## 📊 Key KPIs

* Manufacture Quantity
* Work Order Quantity
* Rejection Rate %
* Wastage
* Production Performance

## 📈 Dashboard Analysis

The dashboards provide insights into manufacturing performance across different dimensions, including:

* Production trends over time
* Machine-wise performance
* Employee-wise performance
* Department-wise performance
* Rejection analysis
* Wastage analysis
* Production and operational KPIs

Interactive filters and slicers allow users to explore the data and analyze performance from different perspectives.

## 🔍 Key Analysis

The project includes analysis of manufacturing operations to identify production patterns, quality-related issues, rejection levels, and performance differences across machines, employees, and departments.

The dashboards were designed to provide a clear and interactive view of manufacturing performance and support data-driven decision-making.
